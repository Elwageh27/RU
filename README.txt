Dental Study Lab — Offline study website
========================================

How to use:
1) Extract the ZIP file.
2) Open index.html in Chrome, Edge, or Firefox.
3) Choose Premalignant Lesions or Benign Tumors.
4) Navigate through the page list. Each page includes:
   - Original slide image from the supplied PDF
   - Arabic explanation and image-reading guidance
   - Original extracted slide text
5) Use the comparison tab, glossary, and interactive quiz.
6) Mark pages as studied; progress is saved in this browser using localStorage.

Notes:
- Internet is not required for the core website. Google Fonts are an optional online enhancement; system fonts will be used offline.
- Original PDFs are included under assets/.
- The content follows the two supplied lecture PDFs. Slides that contain only an image or title are identified as such rather than filled with unsupported claims.
- This is a learning aid, not a clinical diagnostic reference.
